# AI 互审 · Relay

**简体中文** · [English](README.en.md)

<img src="assets/relay-128.png" alt="AI 互审图标" width="96">

把同一个问题交给几个模型时，常常要在网页之间来回复制答案。AI 互审把这几步接起来：先让一个模型写初稿，再交给其他模型检查，最后回到原来的对话里修改定稿。

目前支持 DeepSeek、ChatGPT 和 Kimi 的网页版，使用浏览器里已登录的账号。也可以自行配置 DeepSeek 或兼容接口的 API。网页互审不需要 Key，日常使用不用安装 Node 或 Python。

当前版本：**0.6.1 测试版**，适用于 Windows 上的 Chrome 和 Edge。

## 安装

1. [下载 Windows 安装包](https://github.com/Raylen-berry/ai-relay-app/releases/download/v0.6.1/AI-Relay-0.6.1-Windows.zip)，完整解压。
2. 双击 `安装到本机.cmd`。默认安装到 `%LOCALAPPDATA%\Programs\AI-Relay`，并创建桌面和开始菜单快捷方式。
3. 打开所用浏览器的扩展管理页：Chrome 是 `chrome://extensions/`，Edge 是 `edge://extensions/`。开启“开发者模式”（Edge 中叫“开发人员模式”），点“加载已解压的扩展”，选择**安装目录里的 `extension` 文件夹**。
4. 在这个浏览器里登录本次要用的模型，然后双击桌面的“AI 互审”。

安装脚本优先选 Edge。如果你想用 Chrome，打开 `AI互审启动助手.exe`，选择 Google Chrome，再点“安装到本机 / 创建快捷方式”。

首次加载扩展需要手动完成。安装后请保留整个安装文件夹，浏览器会从中读取扩展。更详细的步骤见 [开始使用](开始使用.html) 和 [换机安装](换机安装.md)。

新旧版本的安装包都放在 [Releases](https://github.com/Raylen-berry/ai-relay-app/releases)，仓库首页保留源码和说明。安装包不含账号、聊天记录或开发依赖。同目录的 `.sha256` 文件可以用来校验下载包。

## 怎么用

在工作台选好模型，输入问题，点“开始互审”即可。三轮、五轮按钮可以快速填好常用顺序，也可以自己修改。接力顺序里的数字对应上方的模型选择：

| 顺序 | 过程 |
| --- | --- |
| `1-2-1` | 模型 1 写初稿，模型 2 审核，模型 1 定稿 |
| `1-2-3-2-1` | 模型 1 写初稿，模型 2、3、2 依次审核，再由模型 1 定稿 |

可以设置 3–9 轮，第一轮和最后一轮都要是模型 1。顺序用到模型 3 时，第三个模型选择才会启用。每次任务会新建模型对话，并在后续轮次中回到对应的原对话。你已有的聊天不会被改写。

运行时保持工作台和任务网页打开。完成后，最终结果会保存在工作台右侧，任务新建的模型页面会自动关闭。想看每轮回答，可以展开“每轮回答与手动处理”。重复点击桌面入口会回到已经打开的工作台。

结果默认用“阅读”视图显示，支持标题、表格、列表和代码块。点“原文”可查看收取的 Markdown；“复制结果”复制这份文字，代码块也可以单独复制。

程序使用网页当前选定的模型和模式。第一次使用，建议先用一个短问题试跑。

### 任务库与批量队列

有回答的任务会自动放进“任务库”，最多保留 100 个。可以搜索问题和结果、加标签、重新载入问题，也可以备份整个任务库。载入只恢复问题与设置，不会自动发送；历史附件需要重新选择。删除任务库记录不会删除模型网站上的对话。

“把当前问题加入队列”会保存当时的问题、附件、模型、顺序和审核分工。在“批量队列”里可以一次粘贴多个问题，每个问题之间留一整行空行，同一问题内可以保留多行材料。点击“运行队列”后依次处理；某一项暂停时，后续项目等待。关闭再打开工作台，队列保持停止，由你决定继续。

### 审核分工与结果核查

展开模型设置里的“每轮审核分工”，可分别选择综合审核、事实与证据、逻辑与遗漏、表达与可读性，或反方检验。分工会写进对应轮次的审核提示，不改变接力顺序。

“结果对比与核查”按行显示初稿与定稿的变化，长文本并排显示全文。“待确认事项”从审核意见中提取候选问题，可能有遗漏，也不会自动判断定稿已解决了哪些；看过后可勾选已处理。“引用来源”收集模型提供的链接，默认标为尚未核验，打开检查后可自行标记。

最终结果可以下载为 Markdown 或 Word（.docx）。点“PDF…”打开打印窗口，选择“另存为 PDF”即可。导出“完整互审”会包含问题、各轮回答，以及候选事项和来源的标记状态。勾选“完成或需要处理时提醒我”，并允许浏览器通知后，会在完成或暂停时提醒；点击通知可回到工作台。系统关闭通知时可能看不到提醒。

### 可选 API

在“设置与记录 → 可选 API”中选择 DeepSeek，或填写自定义兼容接口的地址、模型名称与 Key。接口使用 Chat Completions 格式，地址可以填服务根地址、带版本的基础地址，或完整的 /chat/completions 地址。保存时只申请你填写的接口域名访问权限，随后可在模型下拉框选择这条连接。

DeepSeek 默认填写 https://api.deepseek.com 和 deepseek-flash，使用非思考文字模式；模型名称可按账号和服务商支持情况修改。[DeepSeek 官方接入说明](https://api-docs.deepseek.com/)可查看当前可用模型。

API 首版支持文字互审。带图片或文件的任务请选择网页模型，不会将附件悄悄丢弃。API 和网页模型可以一起参与文字任务。API 请求直接发往配置的服务商，调用按其规则计费；网络中断导致发送状态不明时会暂停，需检查后手动补入回答，不会自动重发。

Key 默认只保存在本次浏览器会话；如勾选长期保存，则放在此浏览器的本机存储中，没有额外加密。任务导出和任务库备份都不包含 Key，换电脑后需重新填写。没有 API Key 仍可继续使用网页互审。

### 图片和文件

点问题框下方的“添加附件”，也可以拖入文件，或在问题框中粘贴截图。一次最多选 10 个文件，单个不超过 20 MB，总计不超过 50 MB。能否读取某种格式，取决于模型网页当前的能力。

选中的附件先保存在本机，开始互审后才会上传到参与任务的模型。同一个任务中，每个模型的对话只上传一次；例如 `1-2-1-3-1`，模型 1、2、3 各收到一次附件，回到原对话时继续使用已上传的文件。

### 任务暂停或一直等待时

工作台会分别提示登录、网页连接、附件和结束标记问题，并给出下一步操作。点“查看当前网页”可打开需要处理的模型页面，再选择：

- 修好当前网页后，点“继续当前步骤”。
- 点“手动处理本轮”，在模型网页上手动发送，再回到工作台点“已手动发送，继续收取”。
- 把该轮的完整回答粘贴到“手动补入回答”，点“保存回答并继续”。

如果程序无法确认一条消息是否已经发出，会先暂停，避免自动重复发送。“暂停”会阻止后续传递，已经发到网页的请求无法撤回，模型也可能继续生成。

如果模型已经回答完，但任务还在等待，可能是模型漏掉了结束标记。可以先暂停，再手动补入该轮完整回答。

关闭工作台后再打开，会恢复本地记录；未完成的任务会先暂停，等你确认后继续。准备另一个问题时，可以点“新问题”，上次结果会保留到新任务开始。

## 保存和换机

问题、提示词、各轮回答和窗口尺寸会保存在当前浏览器中。“设置与记录”里的“导出记录”和“导入记录”使用 JSON 文件。

JSON 包含附件清单，不包含原文件。换电脑时请另外保存附件，在新电脑重新选择；模型账号也要重新登录。

“清空本地记录”会同时删除该扩展保存的任务记录和附件缓存，需要保留的内容请先导出。

## 使用范围

实际操作模型网页的是浏览器扩展，Windows 启动助手负责安装引导和打开工作台。

扩展申请本地存储、写入剪贴板，以及 DeepSeek、ChatGPT、Kimi 网站的访问权限。API 域名与桌面通知在你启用时另行申请。代码不读取 Cookie，没有遥测或远程代码。网页模式通过对应网页发送，API 模式直接访问你配置的接口。

回答完成的判断依赖本轮结束标记、网页生成状态和稳定等待。网页变化或上下文无法核实时，任务会暂停。模型的研究、代理等工具流程，以及 Kimi 桌面端，目前不在支持范围内。

0.6.0 通过 103 项本地测试及 49 项独立 Chrome 功能与边界检查；两个五轮排队任务使用本机模拟 API 跑通。官方 API 尚未配置真实 Key 验收，通知投递使用模拟检查，实际显示需看浏览器和系统设置。网页互审实测见 0.5.2 记录：本机 Chrome 已完成 DeepSeek 与 ChatGPT 的三轮纯文字互审，以及带图片和文本附件的 `1-2-1-2-1` 五轮互审。五轮中返回原对话继续使用附件，最终核对结果正确。Kimi 本次未重新验收。其他验证范围和待验证项目见 [验证记录](验证记录.md)，版本变化见 [更新记录](更新记录.md)。网页控件会变化，测试通过不代表所有账号和模式都能一直正常运行。

## 开发

需要 Node 22 或更新版本。在仓库目录执行：

```sh
npm ci --ignore-scripts
npm test
node tools-check.cjs
```

构建启动助手和图标、生成安装包：

```sh
npm run build
npm run package
```

构建使用系统的 .NET Framework C# 编译器。生成的 ZIP 和校验文件在 `dist/`，不用再放回源码目录。扩展只带运行所需的本地文件，不会加载远程脚本。

`node preview-server.cjs` 可以打开本机界面预览，地址为 `http://127.0.0.1:8766`。`node tools-browser-check.cjs` 在 `http://127.0.0.1:8767` 提供浏览器附件存储和分片传输检查。两者都不会向模型发送问题。

主要文件：

| 文件 | 用途 |
| --- | --- |
| `extension/app.*`、`app-polish.css` | 工作台界面和本地保存 |
| `extension/engine.js`、`issues.js` | 多轮任务流程和卡住原因提示 |
| `extension/markdown-source.js`、`markdown.js` | 收取回答格式和结果阅读视图 |
| `extension/core.js` | 提示词、结果解析和数据导入 |
| `extension/adapters.js`、`content.js` | 模型网页识别和操作 |
| `extension/files.js`、`upload.js` | 附件存储和上传 |
| `extension/background.js` | 工作台窗口入口 |
| `launcher/Launcher.cs` | Windows 启动助手 |

请保留 `manifest.json` 中的 `key`。更改它会改变扩展标识，原有快捷方式和本地数据将无法直接沿用。修改网页适配代码后，需要在扩展管理页重新加载，并刷新模型任务页面。

图标源文件在 `assets/relay-icon.svg`，设计文件在 `design/icon-options`。
