# AI 互审 · Relay

**简体中文** · [English](README.en.md)

<img src="assets/relay-128.png" alt="AI 互审图标" width="72">

把**准备资料、模型处理、交叉审核和成果核对**放在一个工作台里。可以让模型独立完成，也可以让另一模型核查，再回传定稿；每次使用的资料与核对记录会保留。

**Windows · Chrome / Edge · [0.9.0 测试版](https://github.com/Raylen-berry/ai-relay-app/releases/tag/v0.9.0)**

[下载安装包](https://github.com/Raylen-berry/ai-relay-app/releases/download/v0.9.0/AI-Relay-0.9.0-Windows.zip) · [安装说明](docs/安装.md) · [开始使用](docs/使用.md) · [文档导航](docs/README.md)

## 可以做什么

| 功能 | 具体用途 |
| --- | --- |
| **模型互审** | 自动完成初稿、审核与回传定稿，支持自定模型顺序 |
| **数据分析** | 导入表格，本机统计与分组，再准备模型分析报告 |
| **调研报告** | 从选定网页、文件或粘贴资料中整理观点、分歧与出处 |
| **资料问答** | 导入文档，按关键词找到相关段落，再生成带出处的回答 |
| **成果交付** | 接收模型结果或已有正文，逐项核对并导出 Markdown、Word、PDF |

网页模式支持已登录的 **DeepSeek、ChatGPT、Kimi**；文字 API 可选。日常使用不需要安装 Node 或 Python。资料准备和独立成果交付本身不会调用模型。

## 先选哪种执行方式

| 方式 | 过程 | 适合什么 |
| --- | --- | --- |
| **单次完成** | 模型 1 完成，由工具和你核对成果 | 先完成一项任务，再检查结果 |
| **独立核查** | 模型 2 只看原始任务和资料，模型 1 对照两份结果定稿 | 需要另一份不看初稿的判断 |
| **查看初稿后互审** | 按自定顺序审核初稿，再回传模型 1 定稿；3–9 轮 | 需要逐轮检查和修订 |

互审意见是另一份判断；数字、证据和验收条件仍需核对。如何设置模型、顺序与检查重点见[互审](docs/互审.md)。

## 第一次使用

1. 完整解压安装包，双击 **安装到本机.cmd**，再打开桌面的 **AI 互审**。
2. 使用网页模型时，加载安装目录里的 **extension/**，并在同一浏览器配置中登录模型；详见[安装](docs/安装.md)。
3. 输入问题，或用[虚构示例](示例资料/)准备资料；填写验收条件，选择执行方式和模型，点 **开始任务**。
4. 完成后点 **送到成果交付**，核对内容与依据，再导出。

运行期间保持工作台和任务网页打开。遇到登录、连接或发送状态不明时，先看提示，按[常见问题](docs/常见.md)处理。
