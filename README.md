# AI 互审 · Relay

<img src="assets/relay-128.png" alt="AI 互审图标" width="96">

把同一个问题交给几个模型时，常常要在网页之间来回复制答案。AI 互审把这几步接起来：先让一个模型写初稿，再交给其他模型检查，最后回到原来的对话里修改定稿。

目前支持 DeepSeek、ChatGPT 和 Kimi 的网页版。使用你在浏览器里已登录的账号，不需要 API Key。日常使用也不用安装 Node 或 Python。

当前版本：**0.5.0 测试版**，适用于 Windows 上的 Chrome 和 Edge。

## 安装

1. [下载 Windows 安装包](https://github.com/Raylen-berry/ai-relay-app/raw/refs/heads/main/AI-Relay-0.5.0-Windows.zip)，完整解压。
2. 双击 `安装到本机.cmd`。默认安装到 `%LOCALAPPDATA%\Programs\AI-Relay`，并创建桌面和开始菜单快捷方式。
3. 打开所用浏览器的扩展管理页：Chrome 是 `chrome://extensions/`，Edge 是 `edge://extensions/`。开启“开发者模式”（Edge 中叫“开发人员模式”），点“加载已解压的扩展”，选择**安装目录里的 `extension` 文件夹**。
4. 在这个浏览器里登录本次要用的模型，然后双击桌面的“AI 互审”。

安装脚本优先选 Edge。如果你想用 Chrome，打开 `AI互审启动助手.exe`，选择 Google Chrome，再点“安装到本机 / 创建快捷方式”。

首次加载扩展需要手动完成。安装后请保留整个安装文件夹，浏览器会从中读取扩展。更详细的步骤见 [开始使用](开始使用.html) 和 [换机安装](换机安装.md)。

安装包不含账号、聊天记录或开发依赖。同目录的 `.sha256` 文件可以用来校验下载包。

## 怎么用

在工作台选好模型，输入问题，点“开始互审”即可。接力顺序里的数字对应上方的模型选择：

| 顺序 | 过程 |
| --- | --- |
| `1-2-1` | 模型 1 写初稿，模型 2 审核，模型 1 定稿 |
| `1-2-3-2-1` | 模型 1 写初稿，模型 2、3、2 依次审核，再由模型 1 定稿 |

可以设置 3–9 轮，第一轮和最后一轮都要是模型 1。每次任务会新建模型对话，并在后续轮次中回到对应的原对话。你已有的聊天不会被改写。

运行时保持工作台和任务网页打开。完成后，最终结果会保存在工作台右侧，任务新建的模型页面会自动关闭。想看每轮回答，可以展开“查看过程与手动接续”。重复点击桌面入口会回到已经打开的工作台。

程序使用网页当前选定的模型和模式。第一次使用，建议先用一个短问题试跑。

### 图片和文件

点问题框下方的“添加图片 / 文件”，也可以拖入文件，或在问题框中粘贴截图。一次最多选 10 个文件，单个不超过 20 MB，总计不超过 50 MB。能否读取某种格式，取决于模型网页当前的能力。

选中的附件先保存在本机，开始互审后才会上传到参与任务的模型。同一个任务中，每个模型的对话只上传一次；例如 `1-2-1-3-1`，模型 1、2、3 各收到一次附件，回到原对话时继续使用已上传的文件。

### 卡住时继续

网页改版、登录过期或附件解析失败，都可能让任务暂停。可以先查看工作台的提示，再选择：

- 修好当前网页后，点“继续当前步骤”。
- 点“手动接管本轮”，在模型网页上手动发送，再回到工作台点“我已手动发送，继续收取”。
- 把该轮的完整回答粘贴到“手动补入回答”，点“采用回答并跳到下一轮”。

如果程序无法确认一条消息是否已经发出，会先暂停，避免自动重复发送。“停止”会阻止后续传递，已经发到网页的请求无法撤回，模型也可能继续生成。

关闭工作台后再打开，会恢复本地记录；未完成的任务会先暂停，等你确认后继续。准备另一个问题时，可以点“新问题”，上次结果会保留到新任务开始。

## 保存和换机

问题、提示词、各轮回答和窗口尺寸会保存在当前浏览器中。“设置与数据”里可以导出或导入 JSON。

JSON 包含附件清单，不包含原文件。换电脑时请另外保存附件，在新电脑重新选择；模型账号也要重新登录。

“清空本地记录”会同时删除该扩展保存的任务记录和附件缓存，需要保留的内容请先导出。

## 使用范围

实际操作模型网页的是浏览器扩展，Windows 启动助手负责安装引导和打开工作台。

扩展申请本地存储、写入剪贴板，以及 DeepSeek、ChatGPT、Kimi 网站的访问权限。代码不读取 Cookie，没有遥测、服务端或远程代码；模型请求通过各自网页发送。

回答完成的判断依赖本轮结束标记、网页生成状态和稳定等待。网页变化或上下文无法核实时，任务会暂停。模型的研究、代理等工具流程，以及 Kimi 桌面端，目前不在支持范围内。

本地测试覆盖接力顺序、暂停恢复、重复发送保护和附件传输。真实网页的验证范围和待验证项目见 [验证记录](验证记录.md)。网页控件会变化，测试通过不代表所有账号和模式都能一直正常运行。

## 开发

需要 Node 22 或更新版本。在仓库目录执行：

```sh
npm ci --ignore-scripts
npm test
node tools-check.cjs
```

构建启动助手和图标、生成安装包：

```sh
npm run build
npm run package
```

构建使用系统的 .NET Framework C# 编译器。安装包只带运行所需文件，开发依赖不会进入扩展。

`node preview-server.cjs` 可以打开本机界面预览，地址为 `http://127.0.0.1:8766`。`node tools-browser-check.cjs` 在 `http://127.0.0.1:8767` 提供浏览器附件存储和分片传输检查。两者都不会向模型发送问题。

主要文件：

| 文件 | 用途 |
| --- | --- |
| `extension/app.*` | 工作台界面和本地保存 |
| `extension/engine.js` | 多轮任务流程 |
| `extension/core.js` | 提示词、结果解析和数据导入 |
| `extension/adapters.js`、`content.js` | 模型网页识别和操作 |
| `extension/files.js`、`upload.js` | 附件存储和上传 |
| `extension/background.js` | 工作台窗口入口 |
| `launcher/Launcher.cs` | Windows 启动助手 |

请保留 `manifest.json` 中的 `key`。更改它会改变扩展标识，原有快捷方式和本地数据将无法直接沿用。修改网页适配代码后，需要在扩展管理页重新加载，并刷新模型任务页面。

图标源文件在 `assets/relay-icon.svg`，设计文件在 `design/icon-options`。
