安装与使用

AI 互审 · Relay 0.9.0 · Windows 10/11

第一次安装

  1. 从 GitHub Releases 下载 AI-Relay-0.9.0-Windows.zip，右键“全部解压缩”。
  2. 双击 安装到本机.cmd，会优先使用 Edge。需要指定 Chrome 时，打开 AI互审启动助手.exe，选择 Chrome，再点“安装到本机 / 创建快捷方式”。
  3. 默认安装到 %LOCALAPPDATA%\Programs\AI-Relay，并创建桌面快捷方式。安装不需要管理员权限，日常使用也不用 Node、Python 或 API Key。
  4. 在所选浏览器地址栏输入 edge://extensions/ 或 chrome://extensions/，开启开发人员模式，点击加载解压缩的扩展，选择安装目录里的 extension 文件夹。
  5. 在这个浏览器中登录要使用的模型，双击桌面AI 互审即可开始。重新连接网页模型不会自动弹出工作台。

换电脑时保留记录

在旧工作台展开“运行上限与资料保存”，选择保存完整工作包。在新电脑恢复任务、队列、资料正文、表格和独立成果库。工作包不含配置的 API Key、活动会话或附件原文件；换机请重新配置 Key、另外保留并重新选择附件。

模型账号需要在新电脑重新登录。正在运行的任务与标签页不会跨电脑继续，导入也不会自动发送。

尺寸与日常使用

  • 拖动输入框与输出框之间的竖线调整左右宽度，双击恢复等宽。
  • 拖动文字框右下角调整高度；展开“调整工作区”可分别微调。尺寸会自动保存。
  • 输入问题，点击“三轮互审”或“五轮互审”，也可以自定义顺序，点击“开始任务”。长文本转成 TXT 时会等待解析后发送。
  • 任务卡住时，先看工作台显示的原因，点“查看当前网页”处理登录、连接或附件问题。需要接管时点“手动处理本轮”。可以在网页手动发送后回来继续收取，也可以粘贴该轮的完整回答。
  • 完成后可以切换“阅读 / 原文”查看结果，并复制全文或代码。还可以查看总用时和每轮用时细分。应用只关闭自己创建的模型任务页。

任务库与批量处理

已开始的任务（包括等待回答的任务）保存在“任务库”，可以搜索、加标签、备份或重新载入问题。当前问题可加入“批量队列”；批量粘贴时，每个问题之间留一整行空行。队列按顺序处理，某一项暂停时后续等待。

展开“每轮审核分工”可选择本轮检查重点。“结果对比与核查”提供修改对比、候选疑点和引用链接；链接默认尚未核验。可以导出 Markdown、Word，或通过打印窗口保存 PDF。

可选 API 与提醒

“设置与记录 → 可选 API”支持 DeepSeek 和自定义兼容接口，填写地址、模型与 Key 后，可在上方模型选项中使用。API 首版仅支持文字任务；有附件时请选择网页模型。

本机工作台的 Key 默认保存在本次核心进程会话；长期保存使用当前 Windows 账户加密。完整工作包不含配置密钥。直接打开扩展版工作台时使用浏览器存储，详见 API 说明。勾选完成提醒并允许通知后，完成或暂停时会提醒，是否显示还取决于系统通知设置。

添加图片和文件

在问题框下点“添加附件”，也可拖入文件或在问题框粘贴截图。最多 10 个文件，单个 20 MB，总计 50 MB；具体可读格式取决于模型网页。

例如 1-2-1-3-1：模型 1、2、3 的独立会话各上传一次，返回原会话时复用。关闭重开后附件仍在本机。JSON 不包含附件原文件，换机时需另存并重新选择。

更新已有安装

安装到原目录后，在扩展管理页点重新加载，关闭旧工作台，再打开桌面快捷方式，确认页脚 0.9.0。自定义安装位置可在 Install.ps1 中用 -InstallDir 指定。请继续使用原来的安装目录。

沿用原安装目录并保留 data 文件夹；网页扩展与快捷方式应使用同一浏览器配置。网页改版时仍可能需要更新适配；Kimi 桌面客户端暂不支持。

试用三个新流程

工作台顶部可切换数据分析、调研报告和资料问答。先整理数据或资料，准备问题后再选择模型开始任务。示例资料和 试用指南 随安装包提供。

源码、构建脚本和图标原图保存在仓库中。安装包只包含运行所需文件，不包含你的模型登录信息与聊天记录。

已有正文也能核对

顶部“成果交付”支持粘贴正文、导入 UTF-8 TXT / Markdown，或接收互审结果。它建立独立副本，不发送模型请求。补入原文与验收条件，逐项核对，再导出 Markdown、Word 或 PDF。修改正文、依据或条件后需重新核对。
