## English

Open `index.html` in Chrome or Edge and select Play. The offline tutorial supports pause, chapter navigation, fullscreen and playback speed. Narration and captions are in Chinese.

The 2:08 walkthrough covers task input, model selection, acceptance criteria, review, standalone delivery, evidence checks, export and backup in version 0.9.0. It uses a simulated order without calling models and skips generation delays.

For website models, load the extension and sign in within the same browser profile. Existing text can be pasted or imported directly into Delivery. Changes to text, evidence or criteria require new checks.
