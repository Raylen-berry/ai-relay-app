# 可选文字 API

[返回首页](../README.md) · [文档导航](README.md)

不配置 API 也能用网页模型。需要文字接口时，在设置里填写接口地址、模型名称和 Key，再在模型选择中使用。

## 接口范围

当前支持 DeepSeek 与兼容 Chat Completions 的文字接口。本机核心发送请求；直接打开扩展版工作台时还需申请接口域名权限。

程序的 DeepSeek 默认模型名称为 `deepseek-flash`，使用非思考文字模式，可自行修改。自定义服务需接受 Chat Completions、system 消息和 `max_tokens`；不兼容时暂停，核对接口配置。

有图片或文件附件时选择网页模型。API 的支持模型、额度和费用应在自己的服务商处确认；程序中的默认值只是连接配置。

## Key 怎么保存

| 工作台入口 | 默认 | 勾选长期保存后 |
| --- | --- | --- |
| 桌面启动的本机工作台 | 本次核心进程会话 | 用当前 Windows 账户加密后写入磁盘 |
| 直接打开扩展版工作台 | 浏览器会话 | 浏览器长期存储，无额外加密 |

核心退出后，会话 Key 需重填；页面关闭不等于核心退出。**清除保存的 API Key** 可移除会话与长期保存内容。工作包和成果备份不包含配置密钥。

## 发送与中断

API 请求在发送前保存请求标识；已收到的响应可在页面重开后收取。发送状态不明时暂停，不自动重发或切换服务。

输出达到 token 上限时保存部分回答，等待手动处理。限制与恢复见[互审](互审.md)、[常见](常见.md)。不要把尝试次数或输出上限当作金额保证。
