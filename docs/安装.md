# 安装与更新

[返回首页](../README.md) · [文档导航](README.md)

适用于 Windows 上的 Chrome 或 Edge。日常使用不需要安装 Node、Python，也不强制配置 API Key。

## 安装工作台

1. 从 [Releases](https://github.com/Raylen-berry/ai-relay-app/releases) 下载 **AI-Relay-0.9.0-Windows.zip**，完整解压；不要只下载一个 EXE。
2. 双击 **安装到本机.cmd**。默认安装到 `%LOCALAPPDATA%\Programs\AI-Relay`，创建桌面和开始菜单快捷方式。
3. 双击桌面的 **AI 互审**，打开本机工作台。

默认优先选择 Edge。需要 Chrome 时，打开启动助手选择 Google Chrome，再创建快捷方式。安装后保留安装目录，下载的 ZIP 与临时解压目录可以另存或删除。

工作台由 Windows 本机核心启动，资料、任务库、成果交付与可选 API 不依赖网页扩展入口。

## 使用网页模型时再加载扩展

1. 在所选浏览器打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启开发者模式，点 **加载已解压的扩展程序**。
3. 选择**安装目录中的 `extension/` 文件夹**。
4. 在同一浏览器配置中登录要使用的 DeepSeek、ChatGPT 或 Kimi 网页。
5. 回到工作台，选择对应的网页模型。

首次加载由你手动完成，使用已解压扩展期间需要保留开发者模式。模型账号和聊天记录不包含在安装包中。

## 浏览器配置要一致

快捷方式与启动助手绑定所选浏览器的数据目录和配置。首次安装默认使用 `Default`，升级时沿用已有绑定；扩展装在另一浏览器或另一配置中，工作台会无法连接网页模型。

需要指定其他配置时使用安装参数，例如：

```powershell
.\Install.ps1 -InstallDir 'D:\Apps\AI-Relay' -Browser chrome -BrowserProfile 'Profile 1'
```

目录与配置名是示例，应替换为自己实际使用的值；也可通过 `-BrowserDataDir` 指定浏览器数据目录。

## 升级

先保存[完整工作包](数据.md)，处理好进行中的任务，再关闭工作台与本机核心。新版完整解压后安装到原目录，保留 `data/` 与已有浏览器绑定。

扩展管理页点 **重新加载**，再打开桌面快捷方式，核对工作台版本。连接脚本更新后，旧模型任务页面还需刷新，或使用新任务页面。

发布包附 SHA256 文件；旧版本和教程在 [Releases](https://github.com/Raylen-berry/ai-relay-app/releases)。只需了解当前应用行为时，从[使用](使用.md)开始。
