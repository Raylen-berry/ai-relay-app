# 三项流程试用指南

先使用安装包里的虚构示例。准备材料不会调用模型；点击“开始任务”才发送给选定的模型。

## 数据分析

导入“示例资料/销售示例.csv”，选择分组和指标，查看本机统计。准备模型分析，在验收条件中写“关键数字可对照统计表”“说明缺失值和分析限制”。保持单次完成，开始任务。结果中的数字核对块会对照本机指标；没有列出的数字、业务口径和因果解释需要另行核对。下载 Excel、图表和成果记录。

## 调研报告

导入“方案甲.md”和“方案乙.md”。写下比较用途与约束，选择两份材料，准备报告。验收条件可写“每项比较注明依据”“说明资料空白”“没有证据时保留未知”。可以先单次完成，再用相同材料试独立核查。逐条查看引用表述和原文，分别标记有依据、证据不符或无法确认。导出附核对记录的报告。

## 资料整理与问答

导入“差旅制度示例.md”，提问报销期限，查看检索段落，再准备问答。成果的引用应能定位到原文。换一个资料没有涉及的问题，检查模型是否承认材料不足；关键词未找到不能证明规定不存在。整理模式可以建立分类索引和摘要。

## 保存与恢复

展开“运行上限与资料保存”，保存完整工作包。它含表格、资料正文、任务与队列，不含配置密钥、活动会话和附件原文件。恢复前验证文件；导入不会运行任务，原有核对标记作为导入记录显示。请保留一个恢复前的工作包。

## 比较互审是否值得

对同一资料与验收条件，分别试单次完成和独立核查。记录成果是否可用、你花了多少时间检查和返工、等待及调用成本，以及修掉和新引入的错误。中断任务也计入。本安装包的功能测试不能代替这项业务比较。
