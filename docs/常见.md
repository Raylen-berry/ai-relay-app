# 常见问题与恢复

[返回首页](../README.md) · [文档导航](README.md)

| 情况 | 先处理什么 |
| --- | --- |
| 工作台能打开，网页模型无法连接 | 扩展是否启用、是否加载安装目录的 `extension/`、是否与快捷方式绑定同一浏览器配置 |
| 扩展停用了 | 本机资料、任务库和 API 仍可用；网页模型需要恢复扩展连接 |
| 模型要求登录 | 点「查看当前网页」，在对应配置中登录后继续 |
| 附件等待解析或失败 | 看对应模型网页；文件格式能力取决于网页模型，不要反复上传同一附件 |
| 回答已生成却仍等待 | 可能缺少结束或分段确认标记；核对完整回答，再手动处理本轮 |
| 发送状态不明、网络中断 | 先检查网页或接口是否已接收；程序保留内容并暂停，不自动重复发送 |
| API 回答被截断 | 部分回答已保留；补齐后手动处理，或明确调整后续任务的输出上限 |
| 达到运行时间或次数上限 | 查看已保留内容；需要继续时明确增加额度 |
| 关闭重开后任务没继续 | 未完成任务恢复为暂停状态，由你继续；界面关闭后不继续整项调度 |
| 资料网页读不到 | 可能有跨域、跳转、登录或动态加载限制，改为粘贴正文或导入文件 |
| PDF 没有正文 | 当前仅支持文字层，不识别扫描图片；先在其他工具中提取文字 |
| 保存失败 | 先重试或另存正文，再关闭窗口；容量满时先备份并整理旧记录 |

## 手动处理一轮

点 **手动处理本轮**，查看当前模型网页。可以复制待发内容并手动发送，再回工作台点 **已手动发送，继续收取**；或者粘贴该轮完整回答，点 **保存回答并继续**。

确认网页上已发送的内容后再操作，避免把不确定状态当作发送失败。暂停只能阻止后续传递，不能撤回请求。

## 第二个工作台与关闭窗口

只有取得执行权限的工作台能驱动任务，其他窗口可能只读。桌面入口会复用已有工作台；需要接管时按页面提示操作。

任务调度需要工作台保持打开。Windows 本机核心负责入口、存储与 API 请求日志，不代表整项任务可以在关闭界面后持续运行。

## 更新后仍异常

核对工作台版本和安装目录；重新加载扩展，刷新旧模型任务页。网页改版、账号模式变化或接口故障需要修复对应连接，历史实测不能替代当前现场检查。

核对历史验证范围见[验证](验证.md)，安装与配置见[安装](安装.md)。
