# 记录、备份与换机

[返回首页](../README.md) · [文档导航](README.md)

## 数据存在哪里

本机工作台的日常记录自动保存到**安装目录的 `data/`**，与浏览器配置分开。升级应沿用原安装目录并保留此目录。

| 内容 | 是否进入完整工作包 |
| --- | --- |
| 已开始的任务、待处理队列 | 是 |
| 资料正文、表格 | 是 |
| 独立成果库与相关记录 | 是 |
| 配置的 API Key | 否，需重新配置 |
| 模型登录态、活动会话 | 否 |
| 附件原文件 | 否，另行保存和重新选择 |

工作包可能含私密资料正文；选择自己的备份位置。模型网页聊天由账号与网站管理，不由安装包复制。

## 保存和恢复完整工作包

展开 **运行上限与资料保存**，选择 **保存完整工作包**。换机或覆盖导入前先保留一份当前工作包。

恢复前验证整个文件；恢复中断后，下一次取得工作台使用权时会还原恢复前的记录。恢复不会启动模型、队列或活动对话。

带附件的队列项会等待重新选择附件，缺少的 API 连接要另外配置。恢复含成果库的工作包会替换现有成果库；旧版工作包没有成果库时保留现有成果。

成果库单独备份和导入则会添加新副本，清除旧核对状态，不覆盖原成果。两种入口的区别见[交付](交付.md)。

## 到另一台电脑

1. 按[安装](安装.md)完整安装，保留安装目录。
2. 恢复工作包，不恢复运行中的任务。
3. 使用网页模型时，在所选浏览器配置中加载扩展，重新登录账号。
4. 重新配置 API Key，重新选择附件原文件，再由你开始或继续任务。

Windows 账户加密保存的 Key 不能靠复制旧安装目录在新账户中使用。密钥保存方式见 [API](API.md)。

## 旧版浏览器记录迁移

在 **运行上限与资料保存** 中选择 **迁移浏览器旧记录**。先保存当前工作包；迁移会替换本机资料和任务库，保留浏览器原记录，不会启动任务。

API Key 与附件原文件不迁移，需要重新配置。旧安装说明完整保存在[历史](历史.md)，其中浏览器存储描述不适合作为当前本机工作台的操作步骤。
