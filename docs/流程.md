# 数据分析、调研与资料问答

[返回首页](../README.md) · [文档导航](README.md) · [虚构示例试用](试用.md)

顶部切换三个资料流程。先准备表格或文档，再选择模型开始任务；准备本身不发送模型请求。

## 数据分析

导入 CSV、TSV 或 XLSX，首行作为列名，Excel 可切换工作表。本机对当前表格全部行计算缺失值、重复行、合计、均值、中位数、范围和样本标准差。

可以主动选择去空格、删空行、去重复行，或恢复导入时的数据。选择分组与指标后，可下载 Excel 报表、CSV、SVG 图表和统计说明。

模型收到统计摘要、最多 100 项分组结果与前 15 行样例。准备分析时保存本机计算的指标表；软件对照模型报告中的结构化数字核对块，提示错配或不存在的指标。

**数字检查只覆盖核对块**，不验证全文数字、业务口径或因果解释。没有核对块会提示；工作包导入的旧指标不算重新计算。

缺失值不补零；含非数值或超出安全整数范围的列按文本处理；Excel 公式只读已有缓存结果，不重新计算。

## 调研报告

填写研究问题，选取公开 HTTPS 网页、导入文件或粘贴正文。记录实际提供的资料和段落范围，再让模型整理发现、分歧、局限与建议。

网页读取可能受跨域、跳转与网站限制；不带登录 Cookie，也不跟随跳转。动态或登录页面可粘贴正文。当前流程使用你选定的材料，不自动遍历全网研究。

长资料只提供部分正文并说明范围。成果中的 `[S1:P2]` 等编号对应当时的段落快照；每条引用表述分别展示原文，由你标记有依据、证据不符或无法确认。

不存在的编号不能认可；表述或原文变化后旧判断失效。来源可靠与结论成立需分别核对。

## 资料整理与问答

导入 TXT、Markdown、DOCX 正文与表格、有文字层的 PDF，或粘贴正文。可分类、改标题、编辑正文与来源链接；PDF 保留页码，不识别扫描图片。

问答使用本机中英文关键词检索，最多提供 8 个相关段落，你可以取消无关段落。整理模式准备分类索引与摘要；界面和导出记录实际检索、提供的资料范围。

未检索到段落不代表证据不存在。当前没有 OCR、向量检索或任意代码执行。

## 文件与容量限制

| 入口 | 限制 |
| --- | --- |
| 表格文件 | 单文件 10 MB；每张表最多 5,000 行、100 列 |
| Excel 工作簿 | 最多 20 张表、10 万个单元格 |
| 单份资料文件 | 10 MB、20 万字符；PDF 最多 200 页 |
| 资料库 | 最多 50 份，合计 100 万字符 |

这些是资料流程的限制；网页模型附件和独立成果交付有各自范围，见[使用](使用.md)和[交付](交付.md)。
