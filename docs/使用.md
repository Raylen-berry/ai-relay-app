# 开始与管理任务

[返回首页](../README.md) · [文档导航](README.md)

## 第一次任务

1. 直接输入问题，或在顶部选择数据分析、调研报告、资料问答，准备材料。
2. 展开 **任务要求与运行设置**，填写用途、交付形式和验收条件。
3. 选择[执行方式](互审.md)与模型，点 **开始任务**。
4. 观察进度和每轮回答；完成后点 **送到成果交付**，核对并导出。

验收条件一行一项，最多 12 项，每项 500 字。准备材料本身不会调用模型；点击开始后才发送到所选网页或 API。

首次试用可以用[虚构示例](试用.md)，也可以先检查一段短文字。工作台和任务网页在运行中应保持打开，不要改变对应的模型对话。

## 图片和附件

可通过 **添加附件**、拖入文件或粘贴截图准备材料。最多 10 个，单个 20 MB，合计 50 MB；格式是否可读取决于模型网页。

附件先保存在本机，开始任务后才上传。每个模型对话只上传一次，回到原对话时复用；API 仅用于文字任务，有图片或文件时选择网页模型。

附件与资料库导入是不同入口：资料导入会提取正文用于流程，附件交给模型网页处理。备份不包含附件原文件，换机时需要另外保留。

## 任务库与队列

任务库保留已经开始的任务，包括尚未获得回答的任务，最多 100 个。支持搜索、标签与导出；载入问题不会自动发送，附件原文件需重新选择。

可以将问题加入批量队列，按顺序处理。某一项暂停时后续等待；关闭工作台会暂停队列，重开后由你继续。带附件的恢复项目需重新选择附件，缺少 API 连接的项目需先补配置。

## 暂停与手动处理

暂停阻止后续传递，但无法撤回已经发出的请求。关闭再打开工作台后，未完成任务先暂停，不会自动重新发送。

遇到提示时，点 **查看当前网页** 处理登录、连接或附件问题。需要接管时使用 **手动处理本轮**：

- 复制待发内容，在模型网页手动发送，再点 **已手动发送，继续收取**。
- 已有完整回答时，粘贴到手动输入区，再点 **保存回答并继续**。

发送状态不明时先核对网页或接口状态，避免重复提交。回答截断、标记缺失等情况见[常见](常见.md)。

## 完成之后

查看每轮回答与最终结果，再送入[成果交付](交付.md)。独立交付建立副本，修改它不会改变原任务；切换到交付页也不会暂停仍在运行的任务。

工作台可调整左右分栏与文字框尺寸，尺寸会保存。备份与换电脑见[数据](数据.md)。
