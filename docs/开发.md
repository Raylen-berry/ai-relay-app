## 现有检查

```powershell
npm ci --ignore-scripts
npm test
node tools-check.cjs
```

测试覆盖任务状态、网页适配、资料、数字与引用核对、备份恢复、成果库、API 不确定状态和桥连接。资源检查核对语法、脚本顺序、资源与版本。测试数量以本次输出为准。

本地回归使用夹具或模拟兼容服务，不等于当前真实网页模型、收费 API 或实际业务质量验收。过去实测按版本保留在[验证](验证.md)。

## 构建与打包

```powershell
npm run build
npm run package
```

构建使用 Windows .NET Framework 的 C# 编译器和图标依赖，生成启动助手与本机核心。打包将运行文件、`docs/`、示例资料及说明复制到暂存目录，再生成 ZIP 和 SHA256 到 `dist/`。

打包不会发布 GitHub Release。文档改名时同时更新安装和打包复制清单，以及[开始使用页](../开始使用.html)中的链接。

`tools-browser-check.cjs` 是需手动启动的本机附件检查页面，不在 `npm test` 中。界面预览与模拟检查应使用独立目录和虚构资料，不能作为真实账号操作的证据。
