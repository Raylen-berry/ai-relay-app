# AI 互审 · Relay

**简体中文** · [English](English.md)

<img src="../../assets/relay-128.png" alt="AI 互审图标" width="96">

把资料交给模型处理之后，往往还要自己整理答案、找出处、检查数字。Relay 把材料准备、模型执行和成果核对放在一个工作台里，保留每次使用的资料和检查记录。

支持 DeepSeek、ChatGPT 和 Kimi 网页，使用浏览器中已登录的账号。API 是可选项，支持 DeepSeek 和兼容 Chat Completions 的文字接口。日常使用不需要安装 Node 或 Python。

当前版本：**0.9.0 测试版**，适用于 Windows 上的 Chrome 和 Edge。

[看 2 分 08 秒视频](https://github.com/Raylen-berry/ai-relay-app/releases/download/v0.9.0/AI-Relay-Quick-Start-v2.mp4) · [下载离线网页教程](https://github.com/Raylen-berry/ai-relay-app/releases/download/v0.9.0/AI-Relay-Web-Tutorial-v2.zip)

从输入问题、设置互审，到核对成果和导出。视频有中文旁白和字幕；网页解压后打开 `index.html`，可暂停、跳章和调整速度。示例使用模拟订单，生成过程已快进。

## 安装

1. [下载 Windows 安装包](https://github.com/Raylen-berry/ai-relay-app/releases/download/v0.9.0/AI-Relay-0.9.0-Windows.zip)，完整解压。
2. 双击 `安装到本机.cmd`。默认安装到 `%LOCALAPPDATA%\Programs\AI-Relay`，并创建桌面和开始菜单快捷方式。
3. 双击桌面的“AI 互审”，打开本机工作台。资料、任务库和可选 API 可以直接使用。
4. 使用网页模型时，再在 `chrome://extensions/` 或 `edge://extensions/` 开启开发者模式，加载**安装目录中的 extension 文件夹**，并在同一浏览器配置中登录模型。使用已解压扩展期间需要保留开发者模式。

安装脚本优先选择 Edge。使用 Chrome 时，可打开启动助手，选择 Google Chrome，再创建快捷方式。快捷方式和启动助手会绑定所选浏览器的数据目录与配置，升级时沿用已有绑定。首次安装默认使用 Default；其他配置可通过安装参数选择。

本机工作台由安装包内的 Windows 程序启动，不依赖扩展入口。网页连接扩展首次加载需要手动完成。安装后请保留安装文件夹。新旧版本均放在 [Releases](https://github.com/Raylen-berry/ai-relay-app/releases)，安装包附 SHA256 校验文件，不包含账号、任务数据或开发依赖。

## 开始一项任务

1. 直接输入问题，或在顶部选择数据分析、调研报告、资料问答，准备材料。
2. 展开“任务要求与运行设置”，填写成果用途、交付形式和验收条件。验收条件一行一项，最多 12 项，每项 500 字。
3. 选择执行方式与模型，点“开始任务”。准备材料本身不会调用模型。
4. 完成后点“送到成果交付”，核对数字、引用和验收条件，再导出文件。

三项资料流程默认单次完成。需要第二种判断时，可以选择独立核查；也保留原有的多轮互审。

| 执行方式 | 过程 |
| --- | --- |
| 单次完成 | 模型 1 完成任务，随后由工具和你核对成果 |
| 独立核查 | 模型 1 生成成果；模型 2 只看原始任务和资料，不看初稿；模型 1 对照两份结果定稿 |
| 查看初稿后互审 | 按自定顺序检查初稿并定稿，可设置 3–9 轮，首尾使用模型 1 |

不同模型仍可能同时出错。软件将“成果已生成”和“已完成所列人工核对”分开显示，引用编号匹配、来源已核对或模型意见一致都不会自动认可结论。

## 独立的成果交付

顶部的“成果交付”可以单独使用：接收本次互审结果、从任务库选取已完成的成果，或新建后粘贴正文、导入 TXT / Markdown 文件。接收时会建立独立副本，原任务和运行中的任务保持原样。

填写用途、交付形式和验收条件，再逐项检查。正文中的 [S1:P1] 等引用可以对应保存的原文，也能手动补入依据；软件展示的是这句话和这段原文，判断由你记录。修改正文、原文或验收条件后，核对状态会清除。来源可靠与结论成立仍需分别判断。

正文、原文依据与核对记录可一起导出 Markdown、Word 或 PDF，也可备份整个成果库。导入成果库会添加新副本，不覆盖旧成果，旧核对状态不沿用。完整工作包也包含成果库；旧版工作包没有成果库时，会保留现有成果。

此功能不发送模型请求，不需要加载网页扩展。最多保存 50 份成果、合计 500 万字符；每份正文最多 30 万字符。文本文件需为 UTF-8，不超过 1 MB；每段原文最多 850 字。达到上限会提示处理旧记录，不自动删除。具体操作见 [成果交付使用说明](../交付.md)。

## 三项资料流程

### 数据分析

导入 CSV、TSV 或 XLSX，首行用作列名，Excel 可切换工作表。统计基于当前表格全部数据行，显示缺失值、重复行、数值列合计、均值、中位数、范围和样本标准差。含非数值内容或超出安全整数范围的列按文本处理；缺失值不补零；Excel 公式只使用已有缓存结果，不重新计算。

可以明确选择去空格、删空行、去重复行，或恢复导入时的数据。选择分组、指标和计算方式后，可下载 Excel 报表、CSV、SVG 图表和统计说明。模型收到统计摘要、最多 100 项分组结果及前 15 行样例。

准备分析时，会保存一份本机计算的指标表。模型按指定格式列出报告使用的指标，软件检查这些结构化数值是否与指标表一致，提示错误或不存在的指标。**检查只覆盖核对块中的数字**，不验证全文数字、口径是否适合业务或因果解释。没有核对块时会明确提示；从工作包导入的旧指标不会被当作重新计算的结果。

限制：每张表最多 5000 行、100 列，每个工作簿最多 20 张表、10 万个单元格；单个文件最多 10 MB。

### 调研报告

填写研究问题，选取公开 HTTPS 网页、导入文件或粘贴正文。本机工作台读取网页时受网站的跨域限制；扩展版工作台按网站申请权限。两种入口均不使用登录 Cookie、不跟随跳转；动态页面或登录页面可改为粘贴正文。来源由你核对。

软件记录选定资料和实际提供的段落范围，再让模型写发现、分歧、局限和建议。长资料只提供部分正文，会说明截取范围。当前流程基于选定材料，尚未自动遍历全网研究。

成果中的 [S1:P2] 等编号可以对应到当时的段落快照。“成果核对”按每条引用表述列出原文，可标记有依据、证据不符或无法确认，并补充说明。同一段原文用于不同表述时，分别核对；编号不存在时不能标记为有依据。表述或原文变化后，旧判断失效。

### 资料整理与问答

支持 TXT、Markdown、DOCX 正文与表格、有文字层的 PDF，也可粘贴正文。资料可以分类、改标题、编辑正文和来源链接。PDF 保留页码，不识别扫描图片。

问答使用本机中英文关键词检索，最多提供 8 个相关段落，可取消无关段落。整理模式准备分类索引与摘要。界面和导出记录实际检索了多少资料、多少段落，以及本次提供的范围。**未找到证据不能解释为证据不存在。**

限制：每份文件最多 10 MB、20 万字符，PDF 最多 200 页；资料库最多 50 份、总计 100 万字符。尚未实现 OCR、向量检索或任意代码执行。

## 成果、记录与工作包

最终结果支持 Markdown、Word 和 PDF 导出，附引用段落、验收条件、人工核对状态、检索范围和运行限制。任务库保留已开始的任务，包括尚未得到回答的任务；最多保留 100 个，可搜索、加标签和导出。载入问题不会自动发送，附件原文件需要重新选择。

“保存完整工作包”包含任务、待处理队列、资料正文、表格和独立成果库，可在另一个浏览器恢复。恢复前验证整个文件；恢复中断后，下一次取得工作台使用权时会还原恢复前的记录。恢复不会启动模型或队列。带附件的队列项会等待重新选择附件，缺少的 API 连接需另行配置。

工作包**不含配置的 API Key、活动会话和附件原文件**，但可能包含私密资料正文。日常记录自动写入安装目录的 `data` 文件夹，与浏览器配置分开保存；工作包用于另外备份和换机。换电脑后，网页模型仍需加载扩展并重新登录。

旧版浏览器记录可在“运行上限与资料保存”中选择“迁移浏览器旧记录”。先保存当前工作包，迁移会替换本机资料和任务库，保留浏览器里的原记录。API Key 与附件原文件不迁移，请重新配置；迁移不会运行任务。

## 运行上限与中断

可设置自动处理时间、API 发送尝试次数及单次 API 输出 token 上限。限制在新的发送前检查，达到上限后暂停并保留已有内容；需要继续时，由你明确增加额度。单次 API 请求还使用剩余等待时间作为超时限制。已发出的请求可能继续处理，次数和 token 上限不等于账单金额保证。

API 输出被截断时，显示已收到的部分回答，暂停等待手动处理。网络中断导致发送状态不明时，也不会自动重发或切换服务。网页连接、登录、附件和结束标记问题会分别提示。

可以修好网页后继续，或手动发送、补入完整回答。暂停会阻止后续传递，无法撤回已发出的请求。关闭和重开工作台后，未完成任务先暂停。请保持任务网页打开，避免改变对应对话。

## 可选 API 与附件

在设置中填写接口地址、模型名称与 Key。本机核心发送 API 请求；如果直接使用扩展版工作台，仍需申请接口域名权限。DeepSeek 默认使用 [官方接口](https://api-docs.deepseek.com/)和 deepseek-flash，非思考文字模式；模型名称可修改。自定义服务需支持 Chat Completions、system 消息及 max_tokens；不兼容时会暂停，由你检查配置。真实服务支持范围与计费以服务商为准。

本机工作台的 Key 默认只保存在本次核心进程会话。勾选长期保存后，使用 Windows 当前账户加密写入磁盘；核心退出后会话 Key 需重填。直接打开扩展版工作台时，仍使用浏览器会话或无额外加密的长期存储。可通过“清除保存的 API Key”同时移除会话和长期保存内容。备份不含配置密钥。

API 支持文字任务，带图片或文件的任务使用网页模型。附件一次最多 10 个，单个 20 MB、合计 50 MB，先存本机，开始后才上传。每个模型对话只上传一次；格式能否读取取决于网页模型。

## 当前边界

Windows 本机核心负责工作台入口、磁盘保存和 API 请求日志，只监听随机端口的 `127.0.0.1`。需要随机连接凭据，拒绝跨网站写入，数据目录仅向当前 Windows 账户、系统和管理员开放。网页扩展只操作与本机工作台配对、由它创建的任务页面，不能通过这个连接读取任意浏览器标签。

扩展被停用时，本机资料、任务库和 API 仍能使用，网页模型会显示连接提示。API 在调用前保存请求标识，收到的响应可在页面重开后收取；请求状态不明时暂停，不自动重复调用。界面中的任务调度仍需要工作台保持打开，尚不支持关闭界面后继续整项任务。模型网页改版、登录失效、接口故障仍需修复对应连接。

代码不读取 Cookie，没有遥测、远程代码或从资料中执行系统命令的功能。资料正文和模型回答属于待处理内容，不具有更改工具权限的能力。API 提示另设 system 指令，这可以明确边界，但不能保证模型永远不受恶意文字影响。

验证范围和实测结果见 [验证记录](../验证.md)。安装、界面、数据处理和发送恢复的检查，不能替代真实工作质量评估。多轮互审是否值得使用，需要在相同资料、工具与验收标准下比较成果、你的验收时间和总成本。

首次试用可阅读 [三项流程试用指南](../试用.md)，安装包附 [虚构示例资料](../../示例资料)。更多方向见 [功能拓展方向](../方向.md)。
